Credits and limitations

Inspired by Light Teachings by Kia Preston (pkncoder), reference snapshot.

No upstream source code is copied or adapted; the renderer and the CPU tracer implement standard ray-tracing mathematics written for this project.

This is not a pixel-for-pixel reproduction. Ray tracing is an established technique, not our invention. Version 1 supports analytic spheres and planes, up to four point lights, direct illumination, hard shadows and perfect mirrors, with at most four bounces. No glass, global illumination, soft shadows or progressive sampling.

The picture is a WebGL2 image; every number on the page comes from a CPU reference tracer run on the same scene, with a low-resolution CPU fallback when WebGL is unavailable. CPU/GPU agreement is checked by sampled pixel comparisons, not on every device.
